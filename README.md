# Brand strategy assignment

A single-page website for Sarika Dhanshree's assignment (Strategic Thinking, Social Media & Brand Building).

- `index.html` is the whole site: no build step, no dependencies. Illustrations are inline SVG.
- To view locally, open `index.html` in a browser.

## Publish with GitHub Pages
Repo → Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
The site appears at `https://<username>.github.io/<repo-name>/` within a minute or two.
